Como explicarlo

          

            
"Esto no es magia: es una lista con posiciones numeradas."

            
"La primera posicion siempre es 0."

            
"Si hago clic en el indice 2, en Python lo leo como pedido[2]."

            
"Un ciclo recorre una posicion por vez hasta llegar al final de la lista."

          

        


        

          
Lo mas usado en Python

          

            

              
Lista

              
Guarda varios elementos en orden. Se accede por indice: pedido[0].

            

            

              
Diccionario

              
Guarda datos por clave y valor. Ejemplo: {"nombre": "Bandeja"}.

            

            

              
Tupla

              
Se parece a la lista, pero normalmente no se modifica. Sirve para guardar datos fijos.

            

          

        


        

          
Cuando usar cada ciclo

          

            

              
for

              
Usalo cuando quieres recorrer toda la lista con claridad usando range(len(...)).

            

            

              
while

              
Usalo cuando quieres avanzar manualmente con i += 1 mientras la condicion siga siendo verdadera.

            

            

              
Problema real

              
Muchas veces la lista no guarda solo nombres: guarda diccionarios con claves como nombre, precio y tiempo.
