# Mini página de ciclos y arreglos

Esta carpeta es independiente de SAMP.

## Abrir rápido

Opción 1:

- Abre `index.html` directamente en el navegador.

Opción 2:

- En esta carpeta ejecuta `python -m http.server 5500`
- Luego abre `http://localhost:5500`

## Publicar en GitHub Pages

- Sube el contenido de esta carpeta a un repositorio.
- Activa GitHub Pages apuntando a la rama principal y a la carpeta raíz.
- Como es HTML, CSS y JS puro, no necesita build.
